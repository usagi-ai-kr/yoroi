# 관리 라벨

| 라벨 | 대상 | 의미 |
| --- | --- | --- |
| `memo` | 이슈 | 사람만 작성·수정 |
| `plan` | 이슈 | 목표·단계·완료 기준 |
| `work` | 이슈 | 구현·진척·검증 |
| `report` | 이슈 | 요청에 따른 현황 보고 |
| `handle` | 이슈 | 사람의 설정·인증·외부 조치 |
| `hold` | 이슈 | 의존성·결정 대기 |
| `feature` | PR | 기능 추가 |
| `fix` | PR | 버그 수정 |
| `docs` | PR | 문서·스킬 변경 |

성격 라벨과 상태인 hold는 함께 쓸 수 있다. 댓글 자체에는 라벨을 붙일 수 없다.
기존 라벨을 삭제하지 않는다. 호스트의 색상·설명을 우선한다.
