# 전역 CLI 갱신

전역 설치된 yoroi가 레포 최신 빌드와 일치하는지 확인하고 갱신한다.
명령 이름·경로·규칙은 [docs/global-install.md](../../../docs/global-install.md)에서 확인한다.

## 언제 실행

- 버전이 바뀐 변경이 main에 머지된 후
- 전역 CLI 버전이 레포 `package.json`과 다른지 확인할 때
- 전역 설치 환경에서 검증 절차를 수행할 때

## 갱신 절차

1. 레포에서 갱신 스크립트 실행(빌드 → 기존 전역 설치 스크립트 재사용 → 버전 비교, 불일치 시 종료).
2. 읽기 전용 검사로 설치·미설치 상태와 버전 일치 여부 확인.
3. 버전 불일치 시 롤백(제거 후 재설치) 절차를 docs에서 확인.
4. `.env` 사본 갱신 관계를 docs에서 확인.

## 검증

- 갱신 후 `yoroi --version`이 레포 `package.json` 버전과 같은지 확인.
- 읽기 전용 검사 종료 코드(일치 0, 불일치 1, 미설치 2) 확인.

## 보고

- 갱신 전후 버전, 검증 결과만 기록.
- `.env` 값·경로·개인 사용량 원본은 남기지 않음.

## 금지 사항

- `npm publish`, tag, Release는 사용자 명시적 요청이 있을 때만.
- 전역 설치는 사용자 요청 또는 호스트 규칙이 허용할 때만.
- `.env` 값 출력 금지.
- 새 의존성 추가 금지.
