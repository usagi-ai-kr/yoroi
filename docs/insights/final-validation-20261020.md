기본 병렬 check 실패를 통과로 기록하지 않는다. 직렬 통과만으로 원인을 확정하지 않는다.

## 실행 명령

최종 직렬 검증은 아래 네 명령을 순서대로 실행했고 모두 exit 0이었다.

```bash
pnpm run typecheck
node --import ./tests/harness-setup.mjs --import tsx --test --test-concurrency=1 'tests/**/*.test.ts'
pnpm run test:bdd
pnpm run build
```
