# 4차원 역할별 가중 스코어 (p70 오케 70/5/10/15·Cog 비용 병기, 워커 p54 C 유지)

## 사용자 결정과 구현 판단 구분

- 사용자 결정: 소스 OpenRouter·AA·Cognition FrontierCode·OpenCode Data에서 **성능·사용량·속도·가격**을 각각 표준화해 반영한다. AA가 없는 모델도 다른 근거로 평가한다. Free 경로 가격 100 강제는 폐기하고 원래 가격으로 평가한다. 가격 정보가 없는 경우에만 최저 단가 다음 점수를 준다. 두 Top10을 차별화할 가중치·기준은 에이전트가 정한다.
- p70 확정(2026-10-14, p64 70/0/15/15를 대체): 오케 성능/사용량/속도/가성비=70/5/10/15(사용량 켬, 워커와 같은 OR·OCD 토큰), 상한 없이 변형별 채점 후 최고 점수 effort를 대표로 쓴다(동점 낮은 effort). p66 확정: 가성비 차원은 AA I²/P(USD/1M 기반, 높을수록)와 Cognition `cognition_cost`(USD/task, 낮을수록)를 소스마다 min-max한 뒤 max로 합친다(원값 단위 혼합 없음). p56 F(90/0/2.5/7.5)·p58 P1(95/0/2.5/2.5)·p63 상한(high 이하)은 과거 정책이다. 워커30/20/10/40·AA 단가/tok/s·성능 하한.70 유지(p54 C).

## 차원과 소스

모든 표준화는 역할별 후보 풀(접근 가능한 paid + 런타임 검증 free 카탈로그, 최신 세대·제외 계열·후속 규칙 통과)에서 **소스마다 min-max**(0..1, 전원 같은 값이면 1)한다. 오케는 모든 평가 effort 변형을 한 풀로 표준화한 뒤 대표를 고른다. 워커 성능·사용량·AA 속도·단가는 base별 최선값을 전체 모델 풀로 표준화한다.

| 차원 | 소스(좋을수록) | 변환 | 차원 값 |
| --- | --- | --- | --- |
| 성능 | AA 역할 지표(오케·리뷰어=Intelligence, 워커·메신저=Coding) · Cognition main `correct` | 선형, 높을수록 | 두 표준화 값 중 최댓값 |
| 사용량 | 오케·워커 모두 OpenRouter·OpenCode Data 토큰(오케 가중 0.05) | 양수 토큰 log10 | 역할별 최댓값(이중 가산 없음) |
| 속도 | 오케: AA 출력 tok/s · Cognition 소요 분, 워커: AA 출력 tok/s만 | 선형 | 오케 최댓값 / 워커 AA |
| price 키 | 오케 **가성비** Q=I²/(P+.01)·Cog USD/task, 워커 **가격**=AA 혼합 단가 P | 오케 log10(Q) 높을수록·Cog 비용 낮을수록, 워커 log10(P+.01) 낮을수록 | 소스별 min-max 후 오케는 max (USD/1M vs USD/task 원값 혼합 없음) |

- I는 **대표 effort의 AA Intelligence 원값(0~100)**, P는 같은 effort AA 혼합 API단가 `(3입력+출력)/4` USD/1M. 각 변형의 I/P를 사용하며 결측은 단일 default 또는 전 effort 동일값인 소스만 공유한다. Cog 정답률은 성능에만, Cog USD/task는 오케 가성비에만 참여한다(p64, 단위가 달라 원값을 섞지 않고 소스별로 표준화한다). 워커 가격·가성비에는 Cog 비용이 불참한다.
- 오케 AA tok/s와 Cog 작업시간(분)은 각각 표준화 후 speed max. 워커 속도는 AA tok/s만. 계열별 속도·가격/가성비 정의가 다르다.
- Free는 접근 근거만으로 I/P를 바꾸지 않는다. P=0도 분모.01로 계산 가능. I=0·I/P 결측이면 오케 가성비 차원0이며 소스 값은 없음. 풀에 Q 근거가 전혀 없어도0, 전부 같은 양수Q면1. 표시 단가는 원 API 단가(없으면 `-`)다.
- **워커 가격 결측만 .99**: AA 단가 없고 풀에 관측 단가가 있으면 price:missing=.99, 풀 무가격이면0. 오케 가성비 결측은0이며 .99 보정·가중치 재분배가 없다. 오케 price:aa는 정규화 가성비, 오케 price:cognition은 Cog USD/task 역방향 표준화이며 가성비 차원=max(price:aa, price:cognition)이다(p66 확정). 워커 price:aa는 정규화 역단가다.
- 스코어 = 100 × Σ(역할 가중치 × 차원 값). **성능·사용량·속도 결측은 0점이며 가중치를 재분배하지 않는다.**

| 역할 | 성능 | 사용량 | 속도 | 가격 |
| --- | --- | --- | --- | --- |
| 오케스트레이터·리뷰어(마지막 열=가성비) | 0.70 | 0.05 | 0.10 | 0.15 |
| 워커·메신저 | 0.30 | 0.20 | 0.10 | 0.40 |

- 후보 조건: 네 차원 중 하나 이상 근거(Free 접근 행 포함). AA 결측도 다른 소스로 평가한다. 단 워커는 **전체 풀 표준화 후 성능 ≥0.70**만 남긴다(결측은 탈락, 미달 보충도 금지). 하한 뒤 재정규화하지 않는다.
- 계열별 가격·속도 소스 정의가 다르다. 0.70은 정답률이 아닌 풀 상대 표준화 성능이며 후보 풀이 바뀌면 통과 모델도 변한다.

## 임계·정렬·effort

- 임계: 스코어 ≥ 후보 최고 스코어 × 0.85(오케·리뷰어) / 0.75(워커·메신저), 경계 포함. 통과 모델이 먼저, 미달은 보충(▽)이며 스코어순, 동점은 모델명 오름차순이다. 상위 10개로 절단한다.
- 오케 추천 effort: 성능 소스에서 관측된 minimal<low<medium<high<xhigh<max 변형마다 성능·속도·가성비를 같은 effort로 평가한다(상한 없음, max·xhigh 유지 — p63 상한은 p64에서 폐기). 등급 변형이 없으면 default 단일, 등급이 있으면 default는 공유 근거만이다. 소스에 해당 effort가 없으면 단일 default/전 effort 동일값만 공유하고 나머지는 결측0이다. 전 변형 풀 표준화 후 p70 점수(70/5/10/15) 최고를 대표로 고르며 동점은 낮은 effort다. 가성비는 AA I²/P와 Cog USD/task를 각각 표준화한 뒤 큰 값이다. 임계·순위는 대표 점수로 계산한다.
- 워커 추천 effort: 성능 차원을 낸 소스(동점 AA)의 최고 effort이며, AA 속도 최대·단가 최소는 base 최선값을 유지한다.
- GPT-6.1 Sol과 GPT-6 Sol은 독립 후보이며 두 모델 사이 세대 제외·후속 관계·점수 복사를 적용하지 않는다(2026-10-14 사용자 결정).
- 전역 Free-only 제외는 폐기했다. Free 모델도 전체 Top10에 들어간다(Free 별도 섹션은 유지 가능, 접근 근거만 담당). 두 목록 사이 강제 배제·quota는 없다.

## 해석상 주의

- 오케 Q는 I²로 성능을 다시 강조하면서 저가를 우대한다. I가 없는 Cog-only 모델은 AA 가성비0이지만 p64 Cog USD/task 소스로 가성비 차원을 받을 수 있다. 워커 가격은 성능과 무관한 단가 점수이며 결측.99 우대는 별도 한계다.
- Cog 시간 결측은 오케 speed에 영향을 준다. OR/OCD는 워커 사용량에만 기여하며 오케는 표시·기여에서도 제거한다. Q와 Cog 비용 정규화는 관측값만으로 계산하고 결측0을 anchor로 넣지 않는다(오케 가성비 결측은0).
- 가중치 실효 영향은 차원별 분산에도 좌우된다. 워커 품질 하한은 빠르고 싼 저성능 모델의 보충 진입도 막는다. 가격 결측 0.99 우대는 별도 한계로 유지한다.
