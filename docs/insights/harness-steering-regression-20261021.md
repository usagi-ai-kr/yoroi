# 작업 중 정정 전달·통합 회귀 보완 (2026-10-21)

- 관측: idle을 기다리는 coord send가 45초 만료되며, 실행 중 워커에게 독립 리뷰 BLOCK의 전달이 늦었다.
- 확인: `herdr agent prompt --help`는 working 상태에서도 프롬프트 접수를 지원한다.
- 조치: 동일 패널·세션에 delta를 1회 전달, 응답 `agent_prompted`를 확인했다. 모델/세션 변경 없음.
- 접수는 완료나 새 turn_started가 아니다. 기존 작업 산출물과 새 보고서를 대조해 최종 판정한다.
- 재발 방지: 일반 배정은 coord 유지, 작업 중 정정은 공식 지원 확인 후 접수 방식·시각·보고 경로를 기록.
- 관측: 수작업 selection 주입 테스트는 통과했지만 실제 공식 Free catalog→후보→표 연결 회귀는 실패했다.
- 조치: 실제 상위 생성기 출력·공식 카탈로그를 연결한 실패 회귀를 수용 기준으로 고정했다.
- 정책: 표현/부분 helper 통과를 전체 배선 완료로 보고하지 않는다.
