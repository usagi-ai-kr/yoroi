## S1 요구 (w1)

- 기준: 현재 워커 30/20/10/40. 후보 최소 3개: `25/15/10/50`, `20/15/10/55`, `25/20/5/50`.
  더 나은 후보가 있으면 1개까지 추가한다(합 1, 가격 비중 상승).
- 입력은 오늘 저장 데이터(`~/.local/share/yoroi/yoroi.db` 읽기 전용, `--refresh` 금지)로 레터와 같은 렌더 경로를 쓴다.
  `config/score-weights.json`은 수정하지 않는다. 임시 설정은 `/tmp`에서만 쓰고 지운다.
- 현재값 재현이 #138 발행본(15:50 KST) 워커 Top10과 일치하는지 먼저 확인한다(불일치면 원인 보고 후 중단).
- 후보별로 볼 것:
  - 워커 Top10 순위·스코어
  - 진입·이탈(🆕/🚪, 현재값 대비)
  - 파레토(👍) 변화
  - 성능 하한 통과 수
  - 가격 결측(.99 처리) 모델의 위치
  - Free 표 워커 칸 변화
- 비교표는 `scratch/reports/yoroi-p79-w1s-table.md`에 100줄 이하로 쓴다.
- 추천 1개와 근거를 3줄 이내로 적는다(성능 하한 유지 하에서 저가 모델 상향 정도, 결측 처리 왜곡 여부).
