## C2 요구 (w2, D1 보고 후 배정)

- 후보 B에 B': 하한을 min-max 표준화가 아니라 원값(AA coding 절대값 등) 기준으로 두는 안을 포함한다. 원칙 근거는 풀 구성에 따라 하한 의미가 바뀌지 않게 하는 것이다.
- 후보 A에 A': 워커 성능 결측 시 같은 AA의 intelligence_index를 대체 소스로 쓰는 안을 포함한다(소스 간 max 규칙 확장).

- 후보 A(워커 성능 AA 결측 시 OR·OCD 등 다른 소스 대체, 오케 규칙과 일관), B(워커 성능 하한 값 2~3개), C(▽ 보충 자격 강화).
- 각 후보를 현재 가중 30/20/10/40과 p79 S1 추천 가중으로 계산한다.
  - 결과: 워커 Top10 멤버십·순위·🆕/🚪·파레토
  - 과적합: 이웃 파라미터(±0.05 등)에서도 멤버십이 유지되는지, 데이터 요건에서 나온 조정인지
- 기대 멤버십(luna·deepseek·haiku 계열)에 임계를 맞추는 안은 내지 않는다. 근거 요건으로 설명되는 안만 낸다.
- 표는 100줄 이하로 쓴다. 추천 1개와 근거 3줄을 붙인다.
