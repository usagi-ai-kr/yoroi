# 의견 주석 이동 및 리뷰어 파레토 원인 확인

- 사용자: 비고 의견을 표 아래 주석으로 이동, 리뷰어 파레토 공백이 오류인지 기준 문제인지 확인.
- w1: 본문 Top7/댓글 Top15의 3역할 표를 5열(순위·파레토·모델·스코어·effort)로 변경.
- 의견은 각 표 바로 아래 `> 모델명: usagi 기호 · 의견` 형식, 표시된 모델만 모델당 1회·표 순서 유지.
- 의견 없는 모델은 주석 생략. 의견·출처·점수·순위 보존. Free 운영 비고는 유지.
- w3: 리뷰어 파레토 후보 생성→가격/점수 비교→isPareto 전달→렌더 경로 조사.
- 실제 계산·연결 누락인지, 지배 관계와 필터 기준 때문인지 근거로 구분. 기준 임의 완화 금지.
- 파레토 수정은 원인과 소유 파일을 먼저 root에 보고, 이 단위는 진단만 수행.
- w3는 w1 완료 후 독립 리뷰도 담당. 미완료면 pending 보고, 반복 sleep 금지.
- 5분 단위 보고, 파일당 100줄, 기존 next-* 감사 문서·README 보존.
- 구현 검증: pnpm run check, python3 scripts/validate-repo.py, git diff --check.
- 독립 리뷰 통과 후 요청 변경만 경로 지정 커밋, push·원격 게시 없음.
