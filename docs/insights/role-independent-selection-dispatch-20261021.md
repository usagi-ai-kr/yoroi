# 오케·리뷰어 교차 MECE 해제 분배 (2026-10-21)

- 이슈: #252. 정책: 오케스트레이터·리뷰어·워커를 **역할별 독립 선발**하고 역할 간 동일 모델 중복을 허용한다.
- 역할 내부 중복 제거·품질 기준·접근권·effort 상한·가중치·근거 없는 점수 금지는 유지한다.
- 기존 #195의 교대 MECE 문서·테스트 설명은 과거 정책 기록으로 구분하고, 활성 정책·테스트만 갱신한다.

## 구현 계약 (w1)

1. `letter-role-selection.ts`의 `selectRolesAlternating`에서 상대 역할 `oKeys/rKeys/oClosed/rClosed` 교차 배제를 제거한다.
   오케·리뷰어·워커를 각자 독립적으로 선발하고, 역할 내부 `identityKey` 중복만 제거한다.
2. 클로즈드/오픈 웨이트·분류 미확인 모델 모두 역할 간 공유를 허용한다. 워커 선발은 다른 역할에 영향을 주지 않는다.
3. `letter-three-role.ts`의 Top7/Top15가 같은 독립 선발 정책을 쓴다. Top15는 역할별 독립 선발 결과를 그대로 쓰고,
   본문 Top7과 댓글 Top15의 순위 접두가 일치해야 한다. 기존 교대 MECE·Top15 겹침 예외 주석/분기를 정리한다.
4. `letter-three-role-pipeline.ts`와 렌더 경로에서 상대 역할 배제 때문에 후보가 누락되지 않는지 확인한다.
   reviewer policy·worker 선택·Free 표·Mermaid(추후 #253)는 이 단위에서 건드리지 않는다.
5. 테스트: 같은 클로즈드 모델 A가 오케·리뷰어 원순위 1위일 때 양쪽 1위, 같은 기반 모델의 다른 effort/경로 공유,
   오픈/클로즈드/미확인 공유, 워커 독립, 역할 내부 중복 제거, Top7/Top15 독립·접두 일치, 기존 1/0~1/1~3 구성 회귀.
6. `pnpm run check`, typecheck, validate-repo, diff-check, 파일 100줄 이하.
7. 소유 외 수정·커밋·push·외부 쓰기 금지. 보고서에 정책 전후 합성 후보 차이와 테스트 수를 기록한다.
