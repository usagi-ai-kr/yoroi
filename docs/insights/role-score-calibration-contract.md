## 2. 방법 비교: A `T=50+10z` vs B `midrank→inverseNormal→50+10z`

| 항목 | A: 선형 z | B: 역정규(midrank) |
|---|---|---|
| 평균 | **50 정확** (mean z=0) | 50 근사(꼬리 영향) |
| 중앙 | 대칭일 때만 50 | **50 정확**(Φ⁻¹ 대칭) |
| 정규 형태 | **못 만듦**(선형→raw 형태 유지, "근사") | **정확**(출력이 정규, raw 무관) |
| 순위/동점 | **완전 보존**(단사) | 순위 보존·동점은 midrank 동일 T |
| 점수차 정보 | **보존**(상수배 이동) | **파괴**(순서만) |
| 부족 자료 | 표본 작아도 정의 | n 소→극단 p, **clamp 필요** |

- **결론**: A는 차이·순서 보존+평균50 정확하나 정규는 근사. B는 정규 정확하나 점수차 손실. 선택은 설계 검토(임의 확정 금지).

## 3. 엣지·수치 처리 (실제 helper `normalRankScores` 동작으로 교정)

- **구현(권장 B)**: `p=midrank→Φ⁻¹→50+10z`, 0..100 clamp. **rank-normal은 finite·동점에서 정규를 정확히 강제하지 않고 근사다**(작은 n·동점 편향) — 정확이라 단정 금지.
- **n=0(빈 모집단)**: `[]` 반환(빈 입력 그대로).
- **n=1(모델 1개)·상수 점수 모집단**: 전부 `50`(상수는 분산→0이라 50±10 부여 불가).
- **clamp**: p를 극단으로 밀어 Φ⁻¹ 발산을 막고 0..100로 제한.
- **미측정(NaN/±Inf)**: 모집단 집계에서 제외하고 **원값 유지 — 50으로 포장하지 않는다**. **동점**: midrank 동일 → 동일 점수(보존).

## 4. CDF 수학 사실 (양극단 단정 금지)

- **사실**: `X ~ Normal`이면 `Φ((X−μ)/σ) ~ Uniform(0,1)`(확률적 적분 변환), uniform에 `Φ⁻¹` 적용 → 정규.
- 이는 raw가 **정규일 때만 정확**. 정규 아닌 raw에 정규 CDF를 씌우면 균등이 아니라 중앙 근사·꼬리 이탈. **"항상 정확"도 "전혀 무용"도 아니다** → 양극단 단정 금지.

## 6. ▽ 85% relative zone: raw ↔ 보정 score 판단

- **현행**: `belowZone = raw < max(raw) × 0.85`(오케)/`0.60`(워커) — `score.ts:91`, **raw 기준**.
- **보정 score 기준 변경 시 영향**: 보정은 mean 50·std 10 척도 → `85% of max(T)`가 다른 절대 지점이 되어 **▽ 배지·정렬·보충 자격이 흔들림**(상대 zone 의미가 raw와 불일치).
- **판단**: 영향 큼. ▽ 85%는 **raw 기준 유지**가 하위존 판정에 안전하고, 보정값은 Top10 순위·표시 쓰임에 한정하는 것이 무리 없음. 다만 이는 **새 정책 → 임의 적용 금지**, 보정 검증 후 확정.
