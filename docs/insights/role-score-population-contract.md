# 역할별 점수 분포 모집단 계약 (w1 독립 계약, 2026-10-16)

- 소유: 본 문서. **독립 계약만** — w2가 분포 수치를 조사 중이므로 구체 수치·결과는 단정하지 않는다.
- source/config/tests/git 변경 없음, 새 기능 구현·레터 발행 없음. 연관 이슈 [#163](https://github.com/qus0in/yoroi/issues/163)(밴 목록).

## 1. 모집단 정의

- **모집단** = 역할별 전체 후보(**Top10 컷 전**, `letter-top10-score.ts` "역할별 전체 후보").
- **모델 1개당 대표 effort 점수 1개**: 오케 = 점수 최고 변형(동점은 낮은 effort), 워커 = 모델당 행 1개(`score.ts` 대표 변형 규칙).
- **밴 모델 포함**: 밴 대상도 모집단·점수·분포에 그대로 포함한다(관측·점수·분포·이력 삭제 아님).

## 2. 원래 계산 유지 + 보정 분리 정정 (2026-10-16)

- **역할 가중치·산식 불변**: 오케 R linear `70/5/10/15`(성능·사용량·속도·가성비 `I/(P+.01)`), 워커 `30/20/10/40` + 가산(최대 5). 가중치·가산 **원계산은 유지**한다.
- **"점수 무보정"의 범위 분리**: 본 문서의 "점수 무보정"은 오직 **밴 on/off 행위**에만 해당한다 — 밴이 점수를 바꾸지 않고 선발/보충 관문에서만 걸러낸다.
- **별도 보정(정규화) 단계**: 사용자 점수 개선은 역할별 전체 적격 후보를 기준으로 **50 중심 정규분포 보정**을 가하는 것이므로, 이는 밴과 **별개의 추가 단계**다(원계산 뒤). 자세한 계약은 [role-score-calibration-contract.md](role-score-calibration-contract.md).

## 3. 영향 수용 조건

- **랭크**: 밴 모델 외의 상대 서열은 불변. 밴 모델만 Top10에서 빠지므로 하위 모델이 상대 승격한다.
- **보충**: 밴 모델은 **▽ 하한 보충 단계에서 재진입 금지**(공통 ∪ 역할 밴 적용).
- **▽(belowZone)**: 존 하한 판정은 밴과 무관하게 기존 규칙 유지(▽ 표시 자체는 밴으로 발급/삭제하지 않음).
- **가격 결측 표시**: 밴과 무관. 워커 결측 .99·오케 가성비 결측 0 등 기존 결측 처리 유지.
- **기여표**: 밴 모델도 분포·기여 표본에 포함 → 점수 기여(가중×원시)는 밴 on/off로 변동하지 않는다.

## 4. n0 / n1 / 상수 / 동점 / 결측 처리 수용 조건

- 정정(2026-10-16): 직전 본문의 `n0`/`n1`은 모집단·선발 "표본 수 변수"가 아니라 **엣지 케이스 의미**였다 — 아래로 정정한다.
- **n0 = 빈 모집단(n=0)**: 적격 후보 0개 → 보정·분포·선발 불가. 현행대로 빈 목록 처리(현재 동작 유지, 50/정규 부여 없음).
- **n1 = 모델 1개(n=1)**: 분포 산출 불가(분산 없음). 보정 보류 → 원 점수 유지 또는 상수 취급(설계 검토, 임의 확정 금지).
- **상수 점수 모집단**: 분포 편차 0 → z 미정의. 보정 보류·원 점수 유지(설계 검토).
- **동점**: 동점 처리(모델명 순 등)는 밴·보정과 무관하게 기존 규칙 유지.
- **결측**: 결측 처리(워커 .99·오케 가성비 0)는 밴·보정과 무관하게 기존 규칙 유지, 정규화는 관측값만 사용.

## 5. 회귀 수용 조건 (최종)

밴 on/off를 바꿔도 아래 셋이 동시에 성립해야 한다.

1. **모든 모델 점수 및 분포 기준 불변**(점수·모집단·n0·기여 무변경).
2. **Top10 결과만 변화**(선발·보충에서 밴 제외 효과만).
3. **반대 역할 격리**(공통 밴 외 역할 밴이 반대 역할 Top10·분포에 영향 없음).
