# 점수 가중치 외부 설정 (config/score-weights.json, R 1.0.2 오케 가성비 복구)

- 경로·키: 저장소 루트 `config/score-weights.json`. 최상위 `orchestrator`·`worker`·`workerBonusCap`. 오케·워커 모두 `performance`·`usage`·`speed`·`price` 4키. `workerBonusCap`은 워커 가산 점수의 최댓값(기본 5).
- 저장소 기본값(1.2.1): 오케 0.75/0/0.10/0.15(성능/사용량/속도/가성비, 사용량 제외), 워커 0.30/0.20/0.10/0.40(성능/사용량/속도/가격), `workerBonusCap: 5`. **파일이 없으면 이 기본값**을 쓴다. R 1.0.2 오케 0.70/0.05/0.10/0.15는 이력이다.
- 값 오류는 조용히 무시하지 않고 예외로 멈춘다: JSON 파싱 실패, 모르는 역할·차원 키, 역할별 차원 누락, 숫자 아님, 음수, 역할별 합 ≠ 1(허용오차 1e-9).
- 로더 및 테스트: `src/insights/letter-top10-score-weights.ts`(`loadScoreWeights`·`validateScoreWeights`·`SCORE_WEIGHTS`). 정책 상수 `ROLE_DIMENSION_WEIGHTS`(`letter-top10-score-policy.ts`)가 이 값을 쓰며 스코어·레터 표시 문구가 같은 값을 본다. `tests/insights-score-weights.test.ts`가 파일 값=기본값, 파일 없음=기본값, 잘못된 값 예외, 로더 사용을 고정한다.
- 바꾸는 방법: 파일 숫자만 고친다. 코드에 숫자를 복사하지 않는다.
- 형식 근거: 역할별 차원 표는 환경변수로 읽기 어렵고 YAML은 새 의존이라 JSON을 쓴다.
- **오케 가성비 복구(R 1.0.2)**: 오케 가성비 = AA I/(P+.01) log10 정방향(제곱 없음) · Cog USD/task 역방향, 소스별 min-max 후 차원 max, 결측 0. p75 제거·p70 I²는 이력이다. 워커 `price`(AA 혼합 단가, 결측 .99)와 파레토 열은 그대로다.
- **표시 보정(R 확정)**: raw 가중합은 그대로 두고, 역할별 전체 적격 대표 모델 점수에 midrank 정규 순위 변환(50중심·SD 약10)을 **표시 단계**에만 적용한다. ▽·존은 raw 기준 유지. 상세 [role-score-normal-math.md](role-score-normal-math.md).

## 역할별 가중치 및 워커 규칙 (2026-10-15 사용자 확정)

- **워커 사용량 정규 차원 복귀 및 가산 유지**: p85의 '워커 사용량 0' 결정은 2026-10-15 사용자 지시로 번복되어 사용량 0.20 정규 차원으로 복귀했다. 가중치는 성능 0.30, 사용량 0.20, 속도 0.10, 가격 0.40이다. 단, 사용량 0 번복이 가산 소멸을 의미하지 않으며, **워커 가산(`workerBonusCap` 최대 5점 × mean(있는 것만: Cog correct, 사용량 표준화))은 그대로 유지**된다.
- **보유 플랜 가격 우대**: `config/held-plans.json`에 등록된 플랜의 verified 모델 목록은 가격 차원 점수에만 `max(원값, p75)`(후보 풀 가격 차원의 75백분위수)를 적용한다. 가격 결측(priceMissing)은 .99를 유지한다.
- **단가 상한**: 혼합 단가 `(3×입력+출력)/4 > $5/M`이면 존 통과 스코어라도 ▽(미달/상한 표기)로 강등된다(단가 미상은 허용).
- **존 임계**: 워커 임계는 0.75에서 0.60으로 완화(오케 0.85 유지).
- **시뮬레이션 요지**: 워커 존 .60 + 보유 플랜 p75 상향 + 단가 $5/M 상한을 **모두 적용**했을 때 #144 스냅샷 기준 목표 8/8을 달성한다(p75 상향이 없거나 p50 상향이면 7/8). 여기서 '목표'는 사용자가 제시한 워커 후보 선호 계열 평가 기준(코드 규칙 아님)이다. 비용 상한 C는 [4, 6) 구간에서 동일한 결과를 유지(Kimi K3 $6이 들어오는 C≥6부터 7/8)하며 Claude Opus 등 고단가 모델은 ▽ 처리된다.
- **오케 usage 0(1.2.1)**: 판단·계획 역할에서 사용량 지표는 제외(가중치 0)된다. 오케 0.75/0/0.10/0.15, 워커 0.30/0.20/0.10/0.40 + workerBonusCap 5다. 사용량은 워커 전용 차원이다.
- **역할 간 속도 결측 대체(1.2.1)**: 오케 속도 결측 시 워커 AA 속도(max)를, 워커 속도 결측 시 오케 변형 풀 기준 표준화 Cognition 소요값을 가져와 `-` 대신 수치로 표시·반영한다. 고유 속도가 있는 모델은 불변이다. 근거 [letter-121-spec.md](letter-121-spec.md).
