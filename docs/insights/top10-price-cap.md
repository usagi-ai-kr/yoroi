## 규칙 (src/insights/letter-top10-filter.ts)

- 판정 기준: 혼합 단가 = (3×입력 단가 + 출력 단가)/4, USD/1M. off-peak 단가가 적용되는 모델은 적용값으로 판정한다.
- 경계 포함: 혼합 단가 ≥ `PRICE_EXCLUSION_THRESHOLD`(=3)는 제외, 미만은 유지. 무료(0/0)는 유지한다.
- 적용 시점: 후보 파이프라인 1단계(`filterCandidates`)다. 존 임계·보충·파레토 계산 이전에 삭제되므로 제외 모델은 후보 풀에 아예 없다("애초에 제외").
- 단가 미상(priceInput·priceOutput 중 결측)은 판정 불가로 제외하지 않고 기존 규칙(가성비 후순위, ★ 파레토 보류)을 따른다.
- 실효 단가(effort cost_per_task 보정)는 제외 판정에 미사용한다. 판정은 모델의 표가 단가(토큰 가격) 기준이다.
- 저장 단가 행(AA price_1m_*)은 삭제되지 않는다. 제외는 렌더 파이프라인 판정이며 다음 재산출 때 같은 규칙으로 다시 판정한다.
