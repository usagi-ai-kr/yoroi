# 상위 10 지수 점수화 및 가성비 최적 존 설계 (2026-10-12)

Top 10 압축 레터의 오케스트레이터·워커 선정 및 가성비 최적 존(Cost-Efficiency Optimal Zone) 분석 공식과 설계 결정을 기록한다.

## 1. 혼합 단가 및 가성비 지수 공식

- **혼합 단가 (Blended Price per 1M tokens)**:
  `혼합 단가 = (3 × 입력 단가 + 1 × 출력 단가) / 4` (단위: USD / 1M tokens)
  일반적인 에이전틱 작업 흐름(프롬프트·문맥 3 : 생성 1)을 반영한 표준 가중치다.
- **가성비 지수 (Efficiency Index)**:
  `가성비 = 지수 ÷ max(혼합 단가, 0.01)`
  0으로 나누는 오류 방지 및 무료 티어 왜곡 완화를 위해 최저 단가 바닥($0.01)을 적용한다.

## 2. 추천 Effort 및 파레토 경계

- **추천 Effort**:
  동일 모델 제품군(Family: low/medium/high/xhigh 등) 내에서 지수 대비 비용 효율(가성비)이 가장 우수한 effort 변형을 권장안으로 표기한다.
- **파레토 경계 (Pareto Frontier, ★ 표기)**:
  "더 낮은 비용이면서 더 높은 지수를 기록하는 모델이 존재하지 않는" 최적 상태.
  어떤 모델 B도 `Price(B) <= Price(A)`이면서 `Score(B) >= Score(A)` (최소 하나는 엄격한 우위)를 만족하지 못할 때 모델 A를 파레토 최적(★)으로 지정한다.
- **파레토 표시 기준 정정 (2026-10-13)**: 역할 목록 안에서 임계 통과 그룹의 표시 대표 변형끼리 `effectiveCost ?? blendedCost`와 지수를 비교해 ★를 판정한다. 실효 단가가 없으면 혼합 단가를 쓰며, 이전 원 혼합 단가 기준은 이력으로 보존한다.

- **Effort 비용 보정 (2026-10-13 추가 결정)**: AA `modelAlias` 괄호에서 `Max/Xhigh/High/Medium/Low/Minimal`을 읽어 접미사 없는 slug에도 effort를 붙인다(`Reasoning` 등 비등급 토큰은 건너뜀). effort cost/task와 기본 slug cost/task가 모두 있으면 혼합 단가에 그 비율을 곱하고, 한쪽이 없으면 배율 1을 쓴다. 그룹 대표 effort는 역할별 종합 스코어가 가장 높은 변형으로 고른다. AA 기본 alias가 Max인데 기존 대표가 모두 `default`였고, effort별 토큰 소비 차이가 지수÷토큰 단가 비교에 잡히지 않아 생긴 문제를 보정한다.
- **대표 Effort 규칙 이력 정정 (2026-10-13)**: 위 2026-10-12의 가성비 기준 대표 선택은 이력으로 보존하며, effort cost/task 보정과 역할별 종합 스코어를 적용해 변형별 점수를 계산한 뒤 최고 변형을 대표로 선택하는 규칙으로 대체한다.

## 3. 가성비 최적 존 선정 (가중합 폐기, 2026-10-12 사용자 결정)

- **폐기 사유**: 지표 가중합(지수 0.5·가성비 0.4·OR 0.1 등) 점수화는 상충 지표를 하나의 점수로 섞어 해석이 불투명하고, 저지수 고효율 모델의 진입이 가중치에 좌우됐다. "충분한 성능 중 가성비 순" 결정에 따라 임계 필터 + 사전식 정렬로 교체했다.
- **임계**: 오케스트레이터는 그룹 대표의 intelligence_index ≥ 후보 최고값의 85%, 워커는 coding_index ≥ 후보 최고값의 75%인 그룹만 남긴다(경계 포함). 상수는 `src/insights/letter-top10-worker.ts`의 `OPTIMAL_ZONE_THRESHOLDS` 한 곳에 둔다.
- **정렬**: 가성비(지수÷혼합 단가) 내림차순. 무료(0/0)는 최상위, 단가 미상은 맨 뒤(★파레토 보류). 동률이면 OpenRouter 사용량 순위 → 지수 순.
- **채우기 금지**: 통과 그룹이 10개 미만이면 그대로 표시한다.
- **채우기 규칙 대체 (2026-10-13 사용자 결정)**: 위 금지 규칙은 이력으로 보존한다. 존 통과 그룹은 점수순으로 놓고, 부족분은 역할별 최고 변형 지수 내림차순으로 보충해 10개까지 채운다(후보 부족이면 있는 만큼). 대표 변형은 표시 effort·지수와 존 판정에 그대로 쓰며, 그룹 내 최고 지수는 보충 순서에만 쓴다. 지수 결측 그룹은 맨 뒤에서 점수순이다. 보충 행은 `belowZone=true`; 지수 결측은 정규화 0·항상 존 미달·`indexText: '-'`·`indexMissing=true`다.
- **후보 정규화 범위 (2026-10-13)**: 이전의 임계 통과 풀 정규화 설명을 대체한다. 역할별 중복 제거·대표 effort 선정 뒤 전체 역할 후보 풀에서 min-max 정규화하고, 존/보충 분리와 Top10 절단 전에 점수를 계산해 두 그룹의 척도를 맞춘다.
- **전일 비교**: 전일 코호트도 같은 정책(임계+가성비+OR 동점)으로 재계산한다(`previousRanks`).

- **새 정렬 결정 (2026-10-13, 10-12 가중합 폐기를 대체)**: 85%/75%는 자격 필터로 유지하고, 통과 그룹을 단일 점수 내림차순으로 정렬한다. 오케 가중치는 지수/비용/사용량/속도 `0.40/0.40/0.15/0.05`, 워커는 `0.30/0.40/0.10/0.20`이며 비용을 최대 항목으로 두고 워커의 속도 비중을 높인다.
- 정규화 규칙 이력: 새 정렬 결정 당시 임계 통과 대표 변형 풀이라고 적었으나, 채우기 정책과 같은 척도를 쓰도록 전체 역할 후보 대표 풀(존 통과·미달 모두, Top10 절단 전)로 정정했다.
- 정규화는 0~1 min-max: 지수·`log10(토큰)` 사용량·속도는 큰 값이 1, 비용은 `log10(실효 혼합 단가+0.01)` 역방향이다(토큰·속도 0은 유한한 최솟값으로 바닥 보정). 단가 결측 비용·사용량 결측은 0, 속도 결측은 풀 중앙값의 정규화값(속도 전부 미상이면 중립 0.5), 단일값은 1이다. `점수=100×Σ(가중치×정규화값)`; 동점은 지수 내림차순 후 model ID 오름차순이다. 비용 단일값도 분모 0 정책에 따라 1이다.
- 이 점수는 상충 지표를 가성비 우선 사전식으로 처리하던 구 규칙을 대체한다. 가중합을 폐기했던 이유(저지수 고효율 모델의 가중치 민감성)는 이력으로 보존하되, 사용자의 새 결정에 따라 정규화 범위·역할별 가중치를 명시해 비교 기준을 고정한다. 파레토는 기존 혼합 단가·지수만으로 판정한다.
- 날짜·접미사·후속 중복은 후보 풀에서 cutoff 전에 제거하고, 모든 effort 변형의 점수로 대표를 먼저 정한 뒤 대표 그룹의 최고 지수로 임계를 계산한다.

## 9. 역할별 두 목록 (dual-list-111, 2026-10-12)

- 0.8.0의 통합 Top10(#108)을 폐기하고 **🧭 오케스트레이터 Top10**·**🛠️ 워커 Top10** 두 목록으로 되돌렸다. 후보 풀·필터·군집화·임계는 공유하고 판정과 정렬만 목록별로 독립 수행한다.
