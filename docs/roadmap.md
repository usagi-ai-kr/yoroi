# 프로젝트 목표

현재 계획의 원본은 이 문서다. GitHub 계획 이슈로 이전하면 링크와 요약을 남긴다.

| 단계 | 목표 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| Bootstrap | 프로젝트 관리 기반 | 규칙·스킬·템플릿·검증·CI 정의 | 완료 |
| 원격 연결 | Git/GitHub 운영 적용 | 초기화·원격·라벨·보호·CI 실행 확인 | 미착수 |
| 제품 범위 | 첫 모니터링 범위 결정 | 대상 서비스·수집 단위·표시 항목 합의 | 미착수 |
| 개발 기반 | 기술 스택과 실행 환경 결정 | 실행·빌드·테스트·CI 확인 | 미착수 |
| 첫 기능 | 최소 모니터링 흐름 | 수집부터 표시까지 검증 | 미착수 |

- 현재 앱 버전·릴리스·GitHub milestone은 없다. 임의 버전을 부여하지 않는다.
- 첫 기능 범위가 정해지면 `0.1.0` 목표와 완료 기준을 수립한다.
- 구현 시 빌드 버전 원본 하나를 정하고 이곳에 위치를 기록한다.
- milestone은 계획, `vX.Y.Z` tag는 검증된 커밋, Release는 발행 기록이다.
- 일반 절차는 `.agents/skills/semver-milestones/SKILL.md`를 따른다.
