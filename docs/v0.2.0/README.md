## 3. 모순 해소 결과 (5건, 문서별 최소 수정)

- 명명: 각 층 관례 유지 + 매핑표로 통일(schema §4: 이벤트↔kind 4행).
- 상태: run↔공급자 매핑 4규칙 추가(failure §1).
- 캐시: range 인코딩 정의(집계 `24h·7d·30d`, 히스토리 `from..to~limit`, cache §3).
- WS: Upgrade 없는 GET은 `426` + JSON 오류(api §3·WS §1).
- 포트: `ports-design.md` 신규(#34·#37·#38 시그니처 스케치).
- 사용자 확인 필요: (a) `426` 대신 `404` 선호 여부 — 기본안 `426`(근거: 업그레이드 요구 명시).
- 사용자 확인 필요: (b) DB kind를 dot 표기로 통일할지 — 기본안 유지(근거: SQL 관례·매핑표로 충분).
