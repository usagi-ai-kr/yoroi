# 0.2.0 대시보드 UI · 데이터 흐름 · 기준선 설계 (#45–#50)

> 준비 단계: 설치·구현 금지. 근거: #30(현황 카드), #41(`baseline-calc.md`), #42·#43(`api-contract.md`).

## 1. UI 구조 및 디자인 시스템 (#45)

- **스택**: React 19 + Vite + Tailwind CSS v4 + daisyUI v5 + Pretendard 폰트.
- **반응형 레이아웃**: 상단 네비게이션(브랜드, WS 연결 상태 뱃지, 테마 토글) + 탭 바(전체 개요 + 5개 공급자 탭) + 메인 뷰.
- **접근성 및 테마**: daisyUI 시맨틱 테마(다크/라이트), 색상 외 텍스트·아이콘 병행 표기, 스켈레톤 로딩 및 공통 오류 바운더리.

## 2. 데이터 흐름 및 상태 분리 (#46)

- **`ky`**: REST 클라이언트. 기본 타임아웃 5초, 401/오류 정규화 및 AbortController 신호 연동.
- **`TanStack Query`**: 서버 상태 전담 (`/api/v1/usage/latest`, `history`, `providers` 캐싱 및 주기적 갱신).
  - WS `/api/v1/events` 알림 수신 시 `queryClient.invalidateQueries`를 통한 REST 백그라운드 재동기화.
- **`Zustand`**: 순수 UI 상태 전담 (활성 탭, 조회 기간 필터 `24h`·`7d`·`30d`, 툴팁/모달 상태). 서버 응답 덮어쓰기 금지.

## 3. 전체 현황 카드 및 공급자 상세 탭 (#47, #48)

- **전체 개요 카드 (#47)**:
  - 5개 공급자 요약 카드 그리드. 상단에 공급자명·연결 상태(`ok`, `needs-login` 등) 배치.
  - 대표 윈도우 사용률 막대, 리셋 남은 시간(`formatTimeLeft`), 상태 문구 1줄 요약.
- **공급자 상세 탭 (#48)**:
  - 공급자별 전체 윈도우(일간/주간/월간 등) 상세 목록 카드.
  - 잔여율/사용률, 리셋 일시(KST), 신선도(`stale` 여부), 마지막 정상 측정 시각(`lastSuccessAt`) 표시.

## 4. 실제 사용량 막대 · 시간 기준선 · 상태 문구 (#50, #41 정합)

- **막대 구조**: 실제 사용률(0~100%)을 채우는 가로 게이지 바 위에 단일 수직선(세로선 1개)으로 기준선 오버레이.
- **기준선 표시 조건 (`baseline-calc.md` 준수)**:
  - 시작·리셋이 확정된 주간/월간 창에만 표시.
  - rolling 창, `resetAt` 부재, `stale`, 만료된 창, 로그인 필요 시에는 기준선을 숨기고 실제 수치만 표시.
- **자연스러운 상태 문구 예시 (기술 용어 배제)**:
  - 기준선 대비 초과 (+%p): **"빠르게 사용 중"**
  - 기준선 대비 미달 (-%p): **"여유 있게 사용 중"**
  - 리셋 시각 안내: **"한도 초기화까지 3일 6시간"** / **"한도 초기화까지 45분"**
  - 단시간/rolling 창: **"지금 기준 42% 사용"** (기준선 없이 직관적 수치 안내)
  - 장애/인증 만료: **"로그인 필요"** (경고 뱃지), **"연결 확인 필요"**

## 5. ECharts 이력 추이 차트 및 정합성 검증 (#49)

- **차트 구성**: 상세 탭 내 24시간 / 7일 / 30일 SQLite 이력 시계열 라인 차트 (Canvas 렌더링).
- **데이터 처리**: 실제 측정값 점/선 표시. 리셋 경계 및 결측 구간은 null 처리하여 왜곡된 보간선 방지. 확정 창에 한해 0%→100% 선형 기준선 점선 제공.
- **정합성**: `api-contract.md` DTO 구조 준수 및 `baseline-calc.md`의 확정 창 규칙 철저 준용.
