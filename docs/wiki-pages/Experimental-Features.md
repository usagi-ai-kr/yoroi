# 실험 기능 (기본 꺼짐)

아래 기능은 기본 흐름이 아니며 바뀔 수 있습니다. 명시적으로 켜야 동작합니다.

- 3역할 추천: 오케스트레이터·리뷰어·워커별로 모델을 나눠 추천합니다.
  기본 꺼짐.
- 모델 자동 감지: 마지막 정상(last-good) 값을 유지하며 주기 확인합니다.
  기본 꺼짐. 켜면 새 모델·플랜 변경을 알려 주고, 수집에 실패하면 마지막 정상 목록을 유지합니다.
- Arena 코딩 근거: 코딩 벤치 점수를 기존 점수에 더하지 않고 추가 근거로만
  씁니다. 가격·성능 점수를 자동으로 바꾸지 않습니다. 기본 꺼짐.
- Free 모델 실측: `yoroi insights calibrate free --model <id>`로
  명시 실행할 때만 동작합니다. 자동 실행하지 않습니다.
- Actions dry-run: 발행 전 미리보기로만 씁니다. 실제 발행은 별도 확인 후.

실험 기능을 켜기 전에는 각 기능의 도움말(`--help`)을 먼저 확인하세요.
