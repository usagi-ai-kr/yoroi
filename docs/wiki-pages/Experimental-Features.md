# 실험 기능 (기본 꺼짐)

아래 기능은 기본 흐름이 아니며 바뀔 수 있습니다. 명시적으로 켜야 동작합니다.
기준 버전: v1.7.5 (2026-10-20).

## 3역할 추천

- 오케스트레이터·리뷰어·워커별로 모델을 나눠 추천합니다(본문 3역할 Top7, 댓글 3개 Top15 + Free 티어).
- **로컬은 기본 꺼짐**입니다. `YOROI_LETTER_THREE_ROLE=on` 으로 켜면 3역할 경로가 동작하고, 꺼져 있으면 기존 2역할 출력이 그대로 나갑니다.
- **GitHub Actions 프로덕션 발행에서는 `YOROI_LETTER_THREE_ROLE=on` 으로 발행**합니다(레터 발행 워크플로의 env 에 명시).
- 같은 selection 을 본문·댓글에 함께 쓰므로 본문 Top7 은 댓글 Top15 의 앞부분과 같습니다.
- 점수·순위 정책은 3역할 경로에서도 바뀌지 않습니다(역할별 가중치·존 판정은 기존 정책 그대로).

## Free 모델 실측 (보류 · AC 미충족)

- `yoroi insights calibrate free --model <id>` 로 **명시 실행**할 때만 동작합니다. 자동 실행은 없습니다.
- 2026-10-20 기준 사용자 결정으로 **종료·보류** 상태이며, 완료로 표현하지 않습니다.
  자동 실행·비격리 측정·호스트 자격 경로 사용을 하지 않으며, 재개하려면 **새 격리 계획**이 필요합니다.
- 남아 있는 한계: 턴·출력 토큰 상한의 강제, 허용 범위 밖 접근의 선제 차단, 인증과 격리의 충돌.

## 모델 자동 감지

- 마지막 정상(last-good) 값을 유지하며 주기 확인합니다. 기본 꺼짐입니다.
- 켜면 새 모델·플랜 변경을 알려 주고, 수집에 실패하면 마지막 정상 목록을 유지합니다.
- 등록(카탈로그 편입)도 opt-in 이며, 공식 출처 근거가 없는 항목은 편입하지 않습니다.

## Arena 코딩 근거

- 코딩 벤치 점수를 기존 점수에 더하지 않고 **추가 근거로만** 씁니다. 가격·성능 점수·순위를 자동으로 바꾸지 않습니다.
- 소스 수집은 되지만 후보군 반영(카탈로그 등록)은 opt-in 입니다(기본 꺼짐).
- 공식 페이지에 명시된 무료 목록만 근거로 삼고, CLI 관측만으로는 무료로 판정하지 않습니다.

## Actions 발행

- 스케줄 발행(UTC 23:00 = 다음 날 08:00 KST)이 실제 운영 경로입니다. 앱 내부의 08:00 KST 게이트를 통과해야 발행됩니다.
- `workflow_dispatch` 의 `dry_run=true`(기본값)는 **발행 전 미리보기**이며 원격 쓰기가 없습니다. 실제 발행은 `dry_run=false` 로 별도 확인 후 실행합니다.
- OPEN 동일 제목은 skip/댓글 복구, CLOSED만 있으면 같은 제목으로 새 발행합니다(기존 레터는 이력 보존).

실험 기능을 켜기 전에는 각 기능의 도움말(`--help`)을 먼저 확인하세요.
